# invent-agentic-kit

A Claude Code plugin that gives Invent projects a shared way of building with Claude: setting a repo up once.

## Language

### Lifecycle

**Setup**:
A one-time, guided run that creates or brings up to standard a project's Claude Code files, asking before every write. Uses a fixed baseline; never researches the web.
_Avoid_: onboarding, init, install

**Baseline**:
The kit's list of current Claude Code practices that Setup applies.
_Avoid_: standard, rules, best practices (as a noun for the list)
