invent-agentic-kit · Claude Code plugin · v0.5

One setup step.
A shared way of building.

Install the plugin, run one command per project, and every repo gets the same guardrails, the same quality checks and the same workflow for bigger changes.

1 · Setup

/agentic-kit-setup brings a project up to the Invent standard and tidies its Claude Code files. Backed up first.

2 · Guards

Hooks, deny rules and pre-commit checks stop leaked secrets and destructive commands. They run on their own.

3 · Workflow

A suggested loop for bigger tickets: grill, plan, approve, implement, verify, review. Optional.

Demo vs prod: demo means fast work on main and checks that only warn; prod means a branch is required and checks block.

Safe to run: setup backs up the repo's Claude Code files first and prints a restore command. Step 7 (repo-setup) applies its findings without asking: rules for some files only, procedures as skills, "never" as deny rules, personal notes to CLAUDE.local.md.

Install once: /plugin marketplace add <git URL>, then /plugin install invent-agentic-kit@invent-agentic-kit. Update: /plugin marketplace update invent-agentic-kit.

2 · Guards that run on their own

Secret rules keep Claude from reading or editing .env, keys and credentialsalways
protect-secrets also stops secrets from being copied, printed or sent outalways
block-dangerous-commands stops rm -rf ~, git reset --hard, force-push to mainalways
git-safety prod: no commits or pushes on main, work on a branch. Demo: only deleting or force-pushing main is blockedalways
Pre-commit checks lint, format and complexity on every commit: blocking in prod, advisory in demoPython

Blocked? Claude sees the reason and tries another way. If a block looks wrong, tell Claude what you meant. The guards are a seatbelt against slips, not a sandbox.
